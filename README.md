# Studix

## Estructura

- `index.html`: página principal.
- `Estilos/styles.css`: estilos compartidos.
- `Cuenta_Studix/`: inicio de sesión y registro.
- `Leccion_Demo/`: lección de demostración.
- `Secciones_Studix/`: semestres, misiones, avisos, ranking y perfil.
- `Niveles_explicaciones_Matematicas/`, `Niveles_explicaciones_Lenguajes/` y `Niveles_explicaciones_Ingles/`: niveles por materia.

Abre `index.html` para iniciar la navegación.
